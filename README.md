# Enquête implants SOFCPRE

Application hors ligne de saisie terrain. La liste des chirurgiens est chiffrée (AES-GCM) et ne se lit qu’avec le code d’accès.

## Parcours augmentation mammaire (prototype)

Dossier `parcours-augmentation/` : aide-mémoire hors ligne pour chirurgiens (parcours patiente, complications et conduites à tenir, schémas). Prototype de démonstration, aucune donnée patiente.
Adresse : https://mv-terrain.github.io/enquete-congres/parcours-augmentation/
